## 🚀 Déploiement International

### Ajouter un nouveau pays (5 étapes):

1. **Ajouter dans la table countries:**
```sql
INSERT INTO countries (code, name, language, currency_code, ...)
VALUES ('XX', 'Country Name', 'en', 'USD', ...);
```

2. **Ajouter les badges spécifiques:**
```sql
INSERT INTO country_badges (country_code, name, slug, ...)
VALUES ('XX', 'Badge Name', 'badge-slug', ...);
```

3. **Créer fichier de langue (si nouvelle):**
```php
// languages/xx.php
return [
    'common' => [...],
    'project' => [...],
    ...
];
```

4. **Mettre à jour i18n.php:**
```php
'xx' => ['name' => 'Language', 'flag' => '🏴'],
```

5. **C'est tout! Le pays est opérationnel! 🎉**

### Ajouter un nouveau métier:

1. **Ajouter dans trade_categories** avec traductions
2. **Créer champs personnalisés** dans custom_form_fields
3. **Le formulaire est automatiquement généré!**
